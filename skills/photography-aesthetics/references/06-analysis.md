# 分析、釐清與預設值篇

用在兩種情境：**拆解一張既有照片**，以及**需求太模糊、不知道從哪下手**。

---

## 一、逆向拆解流程

拆解的目的不是「形容這張照片」，而是**把它還原成可重新生成的參數組**。每一步只回答一個問題，並且必須引用畫面上的具體線索。判不出來就寫「無法判讀」，不准猜、不准寫「憑感覺」「氛圍很好」。

判讀順序是有依賴關係的，不可跳著做：先定景別，因為景別決定後面還有沒有臉部線索可用（遠景沒有 catchlight，光位只能靠投影方向反推）。

---

### Step 0｜先寫下主體，不寫技法

一句話：誰／什麼 + 在做什麼 + 穿什麼／什麼材質 + 在哪裡。
若這一句寫不出來，代表照片主體不明確，這件事本身就是講評的第一個發現。

---

### Step 1｜景別（19 / 20 / 21 / 23 / 31 / 32）

**線索：畫面下緣切在身體的哪個解剖點 + 人頭高度佔畫面高度的比例。**

| 判定 | 線索 |
|---|---|
| `31 極端特寫` | 器官局部（眼、唇、指節、材質表面）填滿畫面，看不到完整臉部輪廓 |
| `32 特寫` | 頭頂到下巴為主，肩線被切掉或僅露一線；頭高 > 畫面高的 60% |
| `19 近景` | 下緣切在胸線／腋下之間；頭高約畫面高的 30–45% |
| `20 中景` | 下緣切在腰線到大腿中段；能看到手部動作與部分環境 |
| `23 全身照` | 腳完整進畫面且頭頂有留白；人物高度約畫面高的 70–90% |
| `21 遠景` | 人物高度 < 畫面高的 1/3，環境資訊量大於人物資訊量 |

切點若落在關節上（膝蓋、手肘、腕），本身就是一個可指出的構圖缺失。

---

### Step 2｜相機高度（17 / 33 / 39；眼平無編號，但據此重生時仍須明寫）

**線索：地平線（或牆與地板的交線）落在人物身上的高度 + 垂直線的匯聚方向。**

- 看得到頭頂表面、肩膀上緣、地面佔比大，垂直線向下收斂 → `17 高角度拍攝`
- 幾乎垂直向下、人物出現短縮（頭大身體短）、影子從腳底往外放射 → `33 鳥瞰`
- 看得到下巴底面／鼻孔內側、天花板或天空佔比大、垂直線向上收斂 → `39 低角度視角`
- 兩眼連線水平、無短縮、地平線約在人物眼高 → 眼平（無編號；要據此重生時仍須明寫高度基準與 0° 傾角，見 `03-framing.md` 軸 A）

---

### Step 3｜被攝體朝向（26 / 28 / 29 / 30，正面為預設）

**線索：可見耳朵數量 + 鼻樑相對臉部外輪廓的位置。**

- 兩耳皆可見、鼻樑居中、雙眼對稱 → 正面（預設）
- 只見一耳、遠側臉頰仍露出約 1/4、遠側眼角外緣仍在臉輪廓「內」 → `30 四分之三側面`
- 遠側眼球被鼻樑遮掉一半以上、鼻尖突出於臉部外輪廓「之外」 → `29 側面視角`
- 看不到五官，只見後腦與背部 → `28 背面視角`
- 主體的正面與感光面成夾角、環境的水平線條斜向匯聚於畫面外 → `26 斜側視角`

`30` 描述的是「臉朝哪」，`26` 描述的是「相機站哪」，兩者可同時成立，不要混為一談。

---

### Step 4｜主光方位（03 / 04 / 05 / 07 / 13 / 27）

**三個線索交叉驗證，缺一不可：眼神光位置 → 鼻影方向 → 明暗交界線位置。**

**線索 A：catchlight（眼神光）＝ 光源方位的直接讀數。** 眼球是球面鏡，catchlight 在虹膜上的鐘面位置就是光源相對被攝體的方位角，高度就是仰角。

| catchlight 位置 | 讀出的光位 |
|---|---|
| 10–11 點方向、位於瞳孔上緣外側 | 光源在被攝體左前上方約 45° |
| 越靠近瞳孔正中心、越小越圓 | 光源越接近相機軸線 → `27 正面光` |
| 高於瞳孔上緣、幾乎貼虹膜頂端，眼窩下方有暗塊 | 仰角過高 → 接近 `07 頂光` |
| 出現在虹膜下緣（6 點鐘方向） | 光源低於眼平 → `13 底光` |
| 眼中無 catchlight，僅邊緣有亮線 | 光在被攝體後方 → `04 側逆光` 或 `05 背光` |
| 兩個 catchlight 且大小不同 | 主光 + 補光（或主光 + 反光板），回到 Step 6 |

**線索 B：鼻影的方向與終點。** 鼻影落在哪一側，光就在另一側。

- 鼻影短、斜向下延伸到嘴角上方，並在遠側顴骨下形成倒三角亮塊 → 45° 方位、40–60° 仰角（Rembrandt）
- 鼻影橫過人中、一路延伸到臉頰邊緣，臉被切成一半亮一半暗 → `03 側光`（方位約 90°）
- 鼻影短而正下方、眼窩成兩個暗坑、下巴下方有硬陰影、鼻尖上有高光 → `07 頂光`
- 幾乎沒有可見鼻影、陰影藏在主體正後方、皮膚質感被抹平 → `27 正面光`
- 陰影往「上」跑：鼻影在鼻樑上、眉骨陰影落在額頭、下巴亮於額頭 → `13 底光`

**線索 C：明暗交界線（terminator）落在臉的哪一側。** 落在遠側臉頰（亮面朝向相機）＝ broad lighting，臉會顯寬；落在近側（暗面朝向相機）＝ short lighting，臉會顯瘦。這一項要單獨寫出來，因為它是講評時最有可操作性的一句話。

**逆光家族的區分：**

- `04 側逆光`：光在被攝體斜後方 45–135°，臉部大面積在陰影中，但仍有一側被邊光勾出，鼻影朝向相機
- `05 背光`：主體正面幾乎全暗、輪廓全周有光邊、背景亮度明顯高於主體、常伴隨鏡頭耀光與黑位抬升的霧化

---

### Step 5｜光質（09 / 47，特殊光形 15 / 18 / 48）

**線索：陰影邊緣的過渡寬度（penumbra），用「過渡帶佔臉寬的百分比」量。**

| 判定 | 線索 |
|---|---|
| `47 硬光` | 鼻影邊緣在極窄距離內由亮轉暗（過渡帶 < 臉寬 2%）；陰影形狀清晰到能認出鼻子的輪廓；鏡面高光小、亮、邊界銳利；catchlight 是小點 |
| `09 柔光` | 過渡帶 > 臉寬 5%，看不出光源形狀；鏡面高光大而擴散；catchlight 大且常呈方形或矩形（柔光箱／窗） |

補充判讀：背景牆上若出現兩道以上清晰投影 → 多支硬光源（棚拍或 `15 舞台光`）。
畫面中有可見光束穿過空氣（需有介質：煙、霧、灰塵）→ `18 丁達爾光`。
主體正面均勻死白、背景急遽變暗、影子貼在主體背後且邊緣硬、近處物體過曝 → `48 閃光燈`（機頂直打的特徵是「近亮遠暗」的平方反比 falloff）。

---

### Step 6｜補光與光比（43 / 46 / 42 的判定依據）

**線索：陰影側是否還保留紋理與色彩資訊。**

- 暗部接近純黑、色彩資訊消失、看不見暗側眼睛 → 無補光
- 暗部仍能辨識眼球、衣服織紋、髮絲分離 → 有補光

估算光比：目測亮面與暗面相差幾格曝光。差 1 格 ≈ 2:1（平、資訊完整，常伴 `43 低對比度`）；2 格 ≈ 4:1（標準人像）；3 格以上 ≈ 8:1（`46 高對比`，常與 `42 暗色調`、`圖二 06 單光源夜戲` 同時成立）。

反光板線索：下巴下方與頸部亮度被抬起，且眼球下緣出現第二個柔和 catchlight → 低位白板補光。

---

### Step 7｜輪廓光／髮絲光（10 / 14）

**線索：亮線出現在身體的哪一段，以及它有沒有溢到臉上。**

- 亮線只出現在頭髮頂緣／邊緣，臉部亮度不受影響 → `10 髮絲光`
- 亮線沿整個身體側緣連續延伸到肩、手臂、腰，把主體從背景切開 → `14 輪廓光`
- 亮線色溫明顯比主光冷或更飽和（藍、青、洋紅）→ 這是獨立的第二光源，要在標註中分開列

真光 vs 後製描邊：真實邊光會隨髮絲分叉、有亮度衰減、少量溢光落在臉頰邊；後製描邊寬度均勻、貼著輪廓且不進髮絲縫隙。這一點在講評 AI 生成圖時特別常用。

---

### Step 8｜光源與色溫（06 / 08 / 11 / 12 / 36 / 41）

**線索：先在畫面裡找一個中性參照物（白襯衫、白牆、白紙、眼白、水泥、不鏽鋼），看它偏什麼色。**

| 判定 | 線索 |
|---|---|
| `06 暖光源` / `01 暖色調` | 中性物偏橙黃，高光偏黃、陰影偏紅棕 |
| `36 冷光源` / `38 冷色調` | 中性物偏青藍，陰影偏藍紫 |
| `08 窗光` | 方向性強、從畫面一側大面積柔性入射、亮度沿深度快速衰減；有窗框形狀的投影或明顯的漸層 falloff；色溫中性偏冷 |
| `12 火光` | 極暖（橙紅）、來自下方或側下方、亮度不均且邊緣搖曳、只照亮近處 |
| `11 自發光` | 發光體本身在畫面內（螢幕、燈管、霓虹、手機），主體的受光面正對該光源，光源本體過曝成純色塊並向外暈開 |
| `41 雙性照明` | 畫面左右（或前後）被兩種對立色溫夾擊，最典型為橙／青、紅／藍；在明暗交界處看得到色相翻轉 |

若中性參照物在畫面不同區域偏向不同顏色 → 混合光源，必須分開標註主光色溫與環境光色溫。

---

### Step 9｜影調重心（02 / 42 / 44）

**線索：像素分佈的重心落在哪一段，以及最暗處是不是純黑。**

- 大量像素集中在中高調、最暗處仍是淺灰、幾乎沒有純黑 → `44 亮調`
- 大部分畫面在中低調，亮部佔比 < 15% 且集中在主體上 → `42 暗色調`
- 高光被削平成無層次的純白、白色區塊邊緣向外溢出、白色物體與背景失去分界 → `02 過度曝光`
- 整體照度低、雜訊在暗部可見、主體僅由少量光勾勒 → `37 弱光`；反之高光大面積且陰影銳利 → `40 強光`

---

### Step 10｜對比（43 / 46）

**線索：兩端有沒有量，中間調多不多。**

- 兩端都有像素、中間調偏少、黑就是黑白就是白 → `46 高對比`
- 分佈集中在中段、黑位被抬起、畫面像蒙了一層霧 → `43 低對比度`

要區分「低對比是打光造成的（光比 2:1）」還是「後製造成的（黑位抬升 + 高光壓低）」：前者陰影仍有方向與形狀，後者是整張均勻發灰。

---

### Step 11｜飽和（16 / 45）

**線索：看記憶色 —— 膚色、天空、植物、紅色標誌。**

- 紅與藍逼近色域邊緣、膚色偏橘紅、色塊間邊界生硬 → `16 高飽和`
- 膚色接近中性灰、綠色轉為橄欖或土黃 → `45 低飽和`
- 若只有單一色相被保留、其餘被壓成單色 → 選擇性降飽和，往 `圖二 15 沙塵單色` 方向比對

---

### Step 12｜景深與動態（22 / 24 / 25）

**線索：從哪裡開始糊，以及糊的形狀。**

- 清晰範圍窄到只有一隻眼睛在焦內、耳朵已鬆散、背景光點呈圓形或口徑形 bokeh → `25 淺景深`
- 前景、中景、遠景邊緣都可辨識細節、遠處建築線條仍銳利 → `22 深景深`
- 模糊沿單一方向拖曳（主體動、背景清晰），或背景放射狀拖曳而主體清晰（追焦搖攝）→ `24 動態模糊`

務必區分 `24 動態模糊` 與失焦：前者有方向性拖尾且長度可量，後者是各方向均勻擴散。

---

### Step 13｜構圖類型（34 / 35，及圖二 07 / 08）

**線索：主體中軸位置 + 視線出口 + 透視線的匯聚點。**

- 主體垂直中軸與畫面中軸重合、左右負空間相等 → `35 居中構圖`
- 主體被畫面內的實體框住（門框、窗、拱、樹枝、走廊），視線出口被堵死 → `34 封閉構圖`
- 所有透視線收斂到接近畫面正中的單一消失點、左右近似鏡像 → `圖二 07 單點透視對稱`
- 物體表面與感光面平行、幾乎沒有透視匯聚、如平貼的立面 → `圖二 08 平面正面構圖`

---

### Step 14｜風格包比對（圖二 01–24）

只在有明確載體或色彩特徵時才標，沒有就寫「無明顯風格包特徵」。

| 線索 | 指向 |
|---|---|
| 顆粒隨機有機、在中間調最明顯、暗部顆粒不呈方格 | `圖二 18 十六毫米顆粒` |
| 規則方格雜訊、暗部彩噪、高光死白、色彩斷階 | `圖二 14 數位早期` |
| 水平掃描線、色度拖尾、tracking 雜訊、畫面邊緣抖動 | `圖二 17 VHS 錄影帶` |
| 原色極濃、紅綠藍分離產生的彩色鑲邊、膚色偏桃紅 | `圖二 11 三色印片` |
| 微對比高、顆粒細、紅色特別濃郁而不溢、藍天深沉 | `圖二 12 柯達克羅姆` |
| 可見光束穿過煙霧、光有體積、背光為主 | `圖二 05 煙霧體積光` |
| 單一暖／冷點光源、大面積死黑、城市夜景 | `圖二 06 單光源夜戲` |
| 霓虹自發光 + 橙青夾光 + 反射濕地面 | `圖二 13 港片霓虹` 或 `圖二 21 賽博龐克街景`（有無雨／未來建築做區分） |
| 太陽貼近地平線、逆光、低對比、暖到近橘的漫射 | `圖二 04 魔幻時刻` |
| 全畫面單一色相（沙、灰、橙）、極低飽和、強對比 | `圖二 15 沙塵單色` |

### 標準化輸出格式（每次講評都用這個，不得增刪欄位）

```
【技法標註】

主體｜<誰/什麼 + 動作 + 材質/服裝 + 場景>

── 十三軸判讀 ──
景別    ｜32 特寫              ｜線索：下緣切於鎖骨上方，頭高佔畫面 62%
相機高度｜眼平（無編號，重生時須明寫）｜線索：地平線落在眼高，無短縮
朝向    ｜30 四分之三側面       ｜線索：僅見左耳，遠側眼角仍在臉輪廓內
主光    ｜03 側光（方位 75°，仰角 30°）｜線索：catchlight 位於 10 點鐘、鼻影橫過人中至臉頰邊
光質    ｜09 柔光              ｜線索：鼻影過渡帶約臉寬 8%，catchlight 呈大矩形
補光    ｜有，光比約 3:1       ｜線索：暗側仍見眼球與毛衣織紋，下巴下方被抬亮
邊光    ｜10 髮絲光            ｜線索：亮線僅在髮頂、未溢至臉頰
光源色溫｜08 窗光，中性偏冷      ｜線索：白牆呈微青，無橙偏
影調    ｜44 亮調              ｜線索：最暗處為淺灰，無純黑
對比    ｜43 低對比度          ｜線索：中間調密集、黑位抬升，陰影仍有方向
飽和    ｜45 低飽和            ｜線索：膚色接近中性，綠色轉橄欖
景深    ｜25 淺景深            ｜線索：耳朵已鬆散，背景光點呈圓形 bokeh
構圖    ｜35 居中構圖          ｜線索：主體中軸與畫面中軸重合，左右負空間相等

── 風格包比對 ──
最接近：無明顯風格包特徵（信心：高）
（或：圖二 06 單光源夜戲｜信心：中｜依據：<線索>）

── 判讀失敗項 ──
<列出無法判讀的軸與原因；沒有就寫「無」>

── 復刻提示詞 ──
<英文，依 SKILL.md 固定順序組裝：主體 → 景別 → 視角/朝向 → 光位 → 光質
 → 光源與色溫 → 影調與對比 → 色彩 → 景深 → 質感/載體 → 風格總結>

── 最該改的一項 ──
<只講一項，指名軸與替代編號，並說明改了會得到什麼>
```

信心標記規則：三個線索一致 → 高；兩個一致、一個缺失 → 中；只剩單一線索或線索互相矛盾 → 低。低信心項目不得寫進復刻提示詞的核心位置。

### 沒有人臉時的替代線索表

主體是產品、建築、風景時，Step 4–7 改用下列線索：

| 要判的項目 | 替代線索 |
|---|---|
| 光源方位角 | 投影相對物體底部的方向（投影指向哪，光就在正對面） |
| 光源仰角 | 投影長度與物體高度的比值：影長 = 物高 → 45°；影短於物高 → 高仰角；影長於物高 → 低仰角 |
| 光質 | 投影邊緣在遠離物體處的擴散速度；硬光的投影即使拉長仍清晰 |
| 光源大小與形狀 | 曲面（球體、金屬、瓶身、車漆）上鏡面高光的形狀，就是光源的形狀 |
| 補光 | 物體暗面靠近地面處是否被地面反光抬亮 |
| 色溫 | 白牆、白紙、鏡面高光的偏色；鏡面高光通常最接近光源真實色溫 |

## 二、需求釐清問句庫

### 提問策略：最多 3 題，一次問完

硬規則：

1. **三題一次發出，不要來回擠牙膏。** 使用者答完就直接開工。
2. **用二選一或封閉題，不要開放題。**「你想要什麼風格？」得到的答案永遠是「好看的那種」。
3. **使用者已經回答過或已附參考圖的題目，直接跳過，不要湊滿三題。**
4. **三題全部答不出來就用第三章的預設值開工**，並在輸出時把預設值列成清單讓他改。
5. 使用者附了圖 → 先跑第一章逆向拆解，再拿拆解結果去問「哪一項要改」，這比問三題有效得多。

### 三題的固定設計

**Q1 — 主體與用途（決定軸 1 景別、軸 2 相機高度、軸 9 景深、構圖與比例）**

> 「這張圖的主角是誰／什麼，會用在哪裡？（例：社群貼文 / 網站首圖 / 電商主圖 / 印刷）」

對應：用途決定比例與留白，比例決定 `19 近景`／`20 中景`／`21 遠景`／`23 全身照`／`31 極端特寫`／`32 特寫` 的取捨，以及 `22 深景深` vs `25 淺景深`（電商要深、社群人像要淺）與 `35 居中構圖`（需要壓標題時幾乎必選）。這題不能省 —— 沒有主體就沒有圖。

**Q2 — 情緒與時間（決定軸 4 光位、軸 5 光質、軸 6 光源色溫、軸 7 影調）**

> 「看到的人第一秒該有什麼感覺？（溫暖親近 / 冷靜專業 / 神秘戲劇 / 明亮輕快）另外，是白天還是夜晚？」

對應：情緒詞映射到 `09 柔光` vs `47 硬光`、`27 正面光` vs `03 側光` vs `04 側逆光`、`44 亮調` vs `42 暗色調`、`43 低對比度` vs `46 高對比`；時間映射到 `08 窗光`／`06 暖光源`／`36 冷光源`／`11 自發光`／`12 火光`。白天／夜晚這半題最便宜也最關鍵 —— 它一次鎖死光源與色溫兩個軸。

**Q3 — 參照或二選一（決定第 10 層：圖二風格包）**

> 「有沒有一張你覺得對的圖可以給我？如果沒有：你偏向 A 乾淨自然的日光，還是 B 有顏色、有戲劇性的燈光？」

對應：有參照圖 → 直接跑逆向拆解，準確度遠高於任何問答。沒有 → A 導向 `08 窗光 + 09 柔光 + 43 低對比度 + 45 低飽和`（近 `圖二 23 生活寫實`），B 導向 `41 雙性照明 + 11 自發光 + 46 高對比 + 16 高飽和`（近 `圖二 13 港片霓虹`／`圖二 21 賽博龐克街景`）。

## 三、預設值與安全牌

三組安全牌共用同一套基因：**光源單一且方位可辨、對比不極端、飽和不極端**。理由是使用者沒指定時，極端值的期望報酬最低 —— 猜錯極端值要整張重做，猜錯中間值只要調一個軸。

每次使用預設值，輸出時必須附上技法清單，並用一句話交出控制權：「我用了 X 預設，想改哪一項？」不要沉默地套。

---

### 安全牌 A｜人像預設

**技法組合（8 項）：** `20 中景` `30 四分之三側面` `03 側光` `09 柔光` `08 窗光` `43 低對比度` `45 低飽和` `25 淺景深`

```
[subject description], mid shot from the waist up, three-quarter facing toward
camera left, soft directional window light from camera left at 45° azimuth and
30° elevation, large diffused source with a broad shadow transition, white
bounce on the shadow side for a 3:1 lighting ratio, neutral 5600K white
balance, low contrast with gentle highlight roll-off and open shadows, muted
natural palette, accurate skin tone with visible pores and texture, 85mm at
f/2, background separated into soft continuous falloff, uncluttered
neutral-toned setting
```

**為什麼是安全牌：** 45° 柔性側光是人臉最寬容的光位 —— 有立體感但不會把毛孔與皺紋刻出來，鼻影落在嘴角上方形成標準 Rembrandt 三角。3:1 光比在螢幕、印刷、社群壓縮後都不會死黑。四分之三側面比正面顯瘦、又比全側面更容易讓模型保住兩隻眼睛。85mm f/2 是變形最小又能分離背景的組合。低飽和是刻意的：AI 人像最常見的失敗是膚色偏橘，先壓下來比事後救容易。

---

### 安全牌 B｜場景預設

**技法組合（7 項）：** `21 遠景` `08 窗光` `09 柔光` `22 深景深` `43 低對比度` `45 低飽和` `35 居中構圖`

```
[location description], wide establishing shot at eye level, ambient daylight
entering from tall windows on camera right, soft indirect fill filling the
shadows, deep focus at f/8 with foreground, midground and background all
legible, low contrast with open shadows and no clipped highlights, muted
natural palette, symmetrical centered composition with the horizon on the
middle third, 35mm lens with straight verticals, no people in frame
```

**為什麼是安全牌：** 遠景 + 深景深保留最多資訊，使用者事後說「再靠近一點」比說「幫我把糊掉的地方變清楚」容易十倍。窗光是唯一在任何室內場景都成立的動機光源，不需要解釋燈具從哪來。居中對稱在被裁成方形、直式、橫式時都不會壞掉，對社群多版位輸出最耐用。眼平 + 垂直線不歪是空間類圖像的基本專業門檻。

### 安全牌 C｜產品預設

**技法組合（7 項）：** `32 特寫` `26 斜側視角` `09 柔光` `04 側逆光` `14 輪廓光` `22 深景深` `35 居中構圖`

```
[product description], close-up on a seamless neutral mid-grey surface,
three-quarter camera angle slightly above the product, large soft key from
back-left at 135° raking across the surface to describe its material and form,
white card fill from front-right lifting the shadow side, thin rim light
separating the product edge from the background, focus stacked so the entire
product is sharp front to back, centered composition with even margins on all
sides, neutral 5600K white balance, colour-accurate material rendering, clean
contact shadow grounding the product, no props competing with the subject
```

**為什麼是安全牌：** 後側 45–135° 的大柔光是唯一能「同時描述形狀與表面」的穩定解 —— 正面光會讓產品變平，硬光會在包裝上炸出反光。深景深避免電商最常見的災難：商品有一半在焦外。中性灰背景可以直接去背，也可以直接上架。斜側視角同時交代正面與側面，資訊量最大。留邊平均是為了通過各平台的主圖裁切規則。

### 不該用預設值、必須先問的情況

出現以下任一條件，停下來問，不要套預設：

1. **有既有品牌或視覺系統要延續。** 預設值必然與品牌調性衝突，產出等於白做。
2. **有指定投放版位、比例，或需要留白給文案。** 構圖與留白無法事後補救，只能重生成。
3. **主體是特定的真實人物或真實商品，需要維持識別度。** 這時要的是參考圖與一致性流程，不是風格預設。
4. **需求詞裡出現年代或載體（復古、底片、老照片、錄影帶）。** 必須確認是哪個年代 —— `圖二 12 柯達克羅姆`、`圖二 17 VHS 錄影帶`、`圖二 14 數位早期` 的失真方式完全不同。
5. **情緒詞彼此矛盾**（「溫暖又神秘」「乾淨又有戲劇性」）。預設值只能選一邊，猜錯就整組重來，必須讓使用者先二選一。
6. **使用者已經給了一張「不滿意的圖」。** 這是差異需求，不是全新需求 —— 先跑第一章逆向拆解，只改一個軸，不要重新套預設。
7. **用途具紀實、新聞、醫療、法律或證據性質。** 不得加入任何美學技法，只能做中性還原。
8. **需要多張一致（分鏡、系列商品、輪播）。** 必須先鎖定一組固定參數（光位、色溫、鏡頭、比例）再開始第一張，否則第二張起必然不連戲。
