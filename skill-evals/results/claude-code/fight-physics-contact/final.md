### 过载处理（这是方案的核心，不是 prompt 变长）

原需求在 8 秒里塞了 **5 个动作节点 + 4 个相机意图**。复杂接触物理是官方发布材料自己承认的弱项；再叠加环绕、推近、升降，失败模式会互相掩盖，出了问题也查不出是哪一项在坏。处理如下：

| 原需求 | 处理 | 为什么 |
|---|---|---|
| 抓腕 → 转髋挣脱 → 肩撞 → 滑两步 → 定格 | **抓腕放进第一帧当起始状态**（不演抓的过程）；转髋挣脱和肩撞合并为**同一次旋转**（一个因果事件）；滑步 = 可见结果；面对面 = 结束状态 | 一镜一个主因果事件。抓握不再消耗时间和物理预算；"转髋"本来在力学上就是一个动作同时完成抽腕和送肩 |
| 360° 环绕 | **移出主镜** → S2：围绕**静止**对峙的两人环绕 | 交手中环绕必然越轴、把腕部接触挡在身后，且兜帽人物从背面看极易身份漂移；绕静止人物可行性高得多 |
| 快速推近 | 保留为主镜**唯一**相机运动，改成匀速缓推；"快推"放进修订阶梯 | 一镜一个相机意图；快推在接触瞬间会放大形变 |
| 升到俯拍 | **移出** → S3 可选补拍，或干脆不要 | 与推近互斥；俯拍下两件雨衣 + 兜帽几乎不可辨 |
| 面对面定格 | 两人最后 1 秒静止 + 相机停住；**真正的冻结帧在剪辑里做** | 让模型"冻结"常见结果是卡顿或雨也停了 |

**8 秒成片 = 主镜 S1。** 如果你仍要环绕/俯拍的视觉，它们是另外的片段进剪辑（例如 S1 前 6 秒 + S2 环绕 2 秒）；若平台支持首帧，用 S1 末帧作 S2 首帧来压住衔接。

## 2. 最终 prompt

### S1 主镜（8 秒成片，完整版）

```text
【任务与意图】
生成一段约 8 秒的实拍风格单镜头（一镜到底，无剪辑）。雨中天台，恰好两个人近身交手。整段只有一个因果事件：B 用一次转髋动作挣脱 A 对自己右手腕的抓握，并顺势用左肩撞进 A 的胸口；A 被撞得向后滑了两步但站稳没倒。结尾两人面对面停住。

【人物（恰好两人）】
A：成年男性，约 30 岁，中等身材；芥末黄色 PVC 雨衣，兜帽戴在头上，脸在帽檐下可见；深色长裤、黑色橡胶底靴。
B：成年男性，约 30 岁，与 A 体型相近；黑色哑光胶质雨衣，不戴兜帽，短发湿透贴在头上；深色长裤、深色运动鞋。
两人都没有武器、背包、眼镜。两人雨衣颜色全程不互换。

【场景与空间】
傍晚阴天、持续中雨的混凝土天台，地面一层薄积水，映出两人的倒影。背景是半人高的女儿墙和远处城市灯光。画面左后方有一盏天台泛光灯，作主光兼轮廓光，雨丝在逆光里清晰可见。A 身后（画面右侧）至少三米内是空地，没有任何障碍物。

【首帧与站位】
第一帧时抓握已经发生，不表现抓的过程：
B 在画面左侧，侧身面向画面右方；A 在画面右侧，侧身面向画面左方；两人相距一臂。
A 的左手（靠镜头一侧）五指完全握住 B 的右手腕（靠镜头一侧），握点在两人之间、胸口高度、靠近镜头的前景平面。
两人膝盖弯曲、重心低；A 在向自己方向拉，B 在向后抗。
镜头在两人连线的正侧面，胸口高度略低，起幅为全身双人景。

【相机（唯一运动）】
整段只有一次运动：匀速缓慢向前推进，从全身双人景推到腰部以上双人景，约第 6 秒到位后静止。对焦始终在两人身上。没有环绕、没有升降、没有变焦、没有镜头切换。

【动作节拍（时间为大致节奏）】
约 0–1.5 秒：维持起始状态。两人在积水上小幅蹭脚找重心，鞋底擦出很小的水花；雨持续落在兜帽和肩上。
约 1.5–3 秒：B 髋部猛然转动，胸口转向镜头；右肘下沉，手腕朝 A 拇指与食指的缝隙方向拧转，从 A 手里抽出。A 的左手握空，失去对抗力后身体向 B 的方向前倾半步。
约 3–4 秒：B 的旋转不停顿，左肩顺势撞进 A 的胸骨位置。接触瞬间两件雨衣相击，水珠从两人肩上溅开；A 的上半身先被撞离，骨盆和双脚慢半拍才跟上。
约 4–6 秒：A 向画面右侧后退，脚跟在湿地面上打滑两次——每次约半步，鞋底擦出水花，第二次滑动末尾前脚掌抓住地面停住。A 膝盖加深弯曲、双臂张开保持平衡，上半身始终在双脚上方，不倒、手不触地。B 因惯性向前跟进半步，左脚踏实刹住。
约 6–8 秒：两人面对面停住，相距约两步。B 半蹲、双手抬到胸前；A 站稳后重新抬起双手，视线回到 B 的脸。最后约 1 秒两人身体不再移动，只有呼吸起伏和雨水流动；相机已静止。

【物理】
抓握：A 拇指在 B 腕内侧；挣脱时 A 的手指被撬开，手掌明显握空。
肩撞：接触点是 B 左肩前侧与 A 的胸骨；力由 B 的转髋提供，方向水平、由 B 指向 A；A 先头肩后仰，再腰，再脚。
滑步：橡胶鞋底在薄积水上摩擦很低；脚跟先滑、前脚掌抓地终止；两次滑动合计约两步、不超过三步；每次滑动都溅起薄薄的水花。
雨衣：厚重吸水，转身时比身体慢半拍再拍回躯干；B 转髋时黑色雨衣下摆绕腿扫过并甩出弧形水线；A 后滑时黄色兜帽因惯性向前甩再落回。
雨与地面：雨持续、雨量不变；雨点在积水上打出细密涟漪；水从雨衣下摆和帽檐连续滴落。
两人全程至少一只脚与地面接触，没有人倒地。

【可观察的表演】
A：挣脱瞬间视线从 B 的脸落到自己握空的手；被撞后眼神短暂失焦，站稳后重新锁定 B 的眼睛，并做一次明显的呼气。
B：转髋前肩膀先于手臂发力；撞击时盯着 A 的胸口，停住后抬眼看 A 的脸，随后肩膀随呼吸起伏两次。
两人没有台词、不喊叫，表情克制。

【光线与质感】
阴天余光作底，左后方泛光灯作主光与轮廓光，整段光线不变，没有闪电。雨衣表面有水珠和高光，皮肤和头发湿润，地面深色反光。真实实拍质感，35mm 镜头感，自然偏冷的色调。实时速度，没有慢动作、没有速度变化。

【声音】
无对白、无配乐、无字幕。持续雨声和远处城市低频环境声；音效跟动作对齐：雨衣摩擦与拉扯声、肩撞的闷响、两次鞋底打滑的擦水声、停住后两人粗重的呼吸声。

【约束】
全程恰好两个人，没有第三人、没有倒影分身。只发生上述这一次交手：没有拳打、踢击、武器、摔倒。相机只有这一次推进，没有环绕、没有升降、没有剪辑。

【结束状态】
B 在画面左，左脚在前，半蹲、双手抬在胸前，面向右；A 在画面右，比起幅后退约两步，膝盖弯曲、双手抬起，面向左；两人对视；雨持续；镜头为腰部以上双人景、静止；最后 1 秒没有新动作。
```

### S1 精简版（仅用于字数受限的平台，或首轮固定机位物理测试）

```text
实拍风格，约 8 秒一镜到底。雨中混凝土天台，地面薄积水，傍晚阴天，左后方一盏泛光灯逆光照亮雨丝。恰好两人：A 穿芥末黄 PVC 雨衣、戴兜帽，在画面右侧面向左；B 穿黑色胶质雨衣、不戴兜帽、短发湿透，在画面左侧面向右。第一帧 A 的左手已握住 B 的右手腕，握点在两人之间靠镜头一侧。B 猛然转髋、胸口转向镜头，右腕拧转从 A 手中抽出，A 握空前倾；B 顺势左肩撞进 A 的胸口，雨衣相击、水珠溅开；A 上身先后仰，脚跟在湿地上向画面右侧打滑两次，溅起水花，膝盖弯曲、双臂张开，站稳不倒。两人面对面停住，相距两步，双手抬起对视，最后一秒只有呼吸和雨水在动。相机在侧面胸口高度，仅缓慢匀速推进到腰上双人景后静止；无环绕、无升降、无剪辑、无闪电、无慢动作。无对白、无配乐、无字幕；雨声、雨衣摩擦、肩撞闷响、鞋底擦水声、呼吸声。
```

### S2 环绕对峙（可选，约 5 秒；承接 S1 结束状态）

```text
实拍风格，约 5 秒一镜到底。与上一镜相同的雨中混凝土天台、薄积水、傍晚阴天、左后方泛光灯。恰好两人面对面静止对峙：B 穿黑色胶质雨衣、不戴兜帽、短发湿透，左脚在前半蹲、双手抬在胸前；A 穿芥末黄 PVC 雨衣、戴兜帽，相距两步，膝盖弯曲、双手抬起。两人对视，只有呼吸起伏、眨眼、雨水从雨衣下摆和帽檐滴落，双脚不移动。相机以两人中点为轴、胸口高度、匀速环绕 180°，结束时停在起始位置的对面，两人全程都在画面内。无推进、无升降、无剪辑、无慢动作、无闪电。无对白、无配乐、无字幕；雨声与呼吸声。
```

先测 180°；通过后唯一变量改成 360°。

### S3 升到俯拍（可选，约 4 秒）

同 S2 的静止对峙状态；相机从胸口高度匀速升起并转为正俯拍，两人不动，画面内只有雨点在积水上的涟漪和两人倒影变化；无环绕、无推进。若要"定格"，在剪辑里取 S1 或 S3 末帧。

## 3. 验收检查（逐条可答是/否）

**实体**
- 全程恰好两人；无第三人、无倒影分身、无多余的手或脚
- A 黄衣戴兜帽、B 黑衣无兜帽，颜色和兜帽状态不互换、不混色

**动作 / 物理**
- 第一帧即可见 A 左手握住 B 右腕，握点在前景
- 中段 A 左手明显空握，B 右臂自由——抓握确实被破坏，不是穿模消失
- B 左肩与 A 胸口有可见接触；A 的后仰发生在接触**之后**，不是之前
- A 有两次可分辨的脚跟打滑并带水花，不是"走两步后退"，也不是一滑到底
- A 始终有脚触地、手不触地、不倒；B 不滑不倒
- 雨衣像湿重胶布：滞后、拍回、甩水线；不是薄布飘动
- 雨持续、雨量不变、无闪电、光线不变

**表演**
- A：握空时视线落到手 → 被撞失焦 → 站稳后锁定 B 并呼气
- B：撞击时盯胸口 → 停住后抬眼 → 肩膀随呼吸起伏

**相机**
- 只有一次匀速推进，约第 6 秒后静止；无环绕、无升降、无变焦、无切换；结尾两人脸都可见

**结束状态**
- B 左 / A 右，相距约两步，面对面、双手抬起；最后约 1 秒无新动作

**声音（若平台出声）**
- 无对白、无配乐、无字幕；雨声持续；打滑、肩撞、呼吸与画面对齐——需实际听，播放图标不算证据

**时长**
- 实测输出时长与你在平台所设的值一致；节拍有可能整体偏快或偏慢，这是正常的语义漂移

## 4. 失败风险（不做成功保证）

- **两次接触串联仍是最高风险**：抓握穿模、手腕"消失"而非抽出、肩膀穿过胸口、A 在接触前就后退。结构化写法降低的是歧义，不是模型的物理能力上限。
- **角色互换**：两个湿衣人物在雨中容易被模型混成"谁撞谁"；颜色 + 兜帽差异是缓解，不是保证。
- **额外动作**：拳、踢、摔倒、第三人；或动作提前做完后用重复动作填满 8 秒。
- **滑步退化**：渲染成走步、或直接摔倒、或滑出三米。
- **材质退化**：雨衣变薄布、雨变雾、雨停、自动加闪电。
- **相机不守约**：擅自加环绕/升降，或把推进做成变焦。
- **时长与节奏**：时间码是语义的，实际片长和节拍位置要实测。
- **声音**：生成音频是脚手架，最终混音大概率要在后期替换。

## 5. 修订阶梯（每级只改一个变量；全部为前瞻性、未经实测）

基线：同一 prompt、同一参数先跑 2 次，分清随机波动和系统性缺陷。预算上限由你的项目定，别套通用重试次数。

1. **抓握/挣脱不成立**（穿模、腕没抽出、A 手不空）
   改：加一张"A 左手握住 B 右腕"的静帧作首帧图；prompt 不动。
   诊断：起始状态是否根本没被建立。
   停/路由：平台不支持首帧，或加首帧后两次仍失败 → 在挣脱点拆成 S1a（抓握→抽腕）/ S1b（肩撞→滑步→对峙）。

2. **肩撞穿透或 A 先退后撞**
   改：删掉推进，改固定机位；其余不动。
   诊断：相机运动是否在和动作竞争。
   停/路由：仍失败 → 在撞击点拆镜，S1b 以"A 上身已被撞离"为起始状态；或剪辑里在撞击处切一个脚部特写插入（单独生成"一双靴子在积水上打滑两次"，画面只含脚和地面，风险最低）。

3. **A 摔倒 / 走步 / 滑太远**
   改：只改 4–6 秒那一拍的文字（例如改成一次滑步 + "脚跟拖出两道水痕"）；其余不动。
   停/路由：仍失败 → 接受一次滑步，或走第 2 级的脚部插入路线。

4. **身份互换 / 混色 / 多出一人**
   改：只加强区分（例如 B 改深蓝雨衣，或 A/B 体型明显不同）。
   停/路由：仍失败 → 首帧图路线（同第 1 级）。

5. **动作全部通过，想要更多相机感**
   改：推进改为"推进同时小幅弧线移动约 30–45°"，动作文字不动。
   停/路由：接触可读性下降 → 退回缓推版本；环绕只留在 S2。

**通用停止条件**：同一硬缺陷在相关的孤立修改后仍复现（例如两轮）→ 拆镜 / 首帧 / 后期，不再往 prompt 里加形容词；修好一项就弄坏另一项的振荡 → 拆镜。停止时保留最后一个通过的版本、失败假设和证据。
