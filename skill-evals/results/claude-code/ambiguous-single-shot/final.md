## 最終 Prompt(可直接貼上)

```text
【任務】生成一支 8 秒單鏡頭電影感短片。夜晚大雨中,一個女生走出便利商店,發現自己的紅傘被人拿走了。

【人物與道具】畫面中恰好兩個人。主角:20 出頭的女生,米色大衣、白色球鞋,右手提著一個便利商店塑膠袋。門口右側有一個金屬傘架,裡面只插著兩三把深色黑傘——沒有紅傘。畫面左側中遠處:一個背對鏡頭的陌生路人,撐著一把鮮紅色的傘,正走遠。全片只出現這一把紅傘,女生手上始終沒有傘。

【空間】便利商店自動玻璃門位於畫面中央偏後,店內暖白日光燈從她身後透出;門外雨棚下是濕漉漉的人行道,傘架在畫面右側,街道向畫面左側延伸,遠處有一盞路燈和霓虹招牌。

【鏡頭】單一鏡頭,不剪接。中景起幅,鏡頭在雨中緩慢向前推近至她的中近景,焦點始終在女生臉上;紅傘路人在左後景以淺景深虛化呈現。35mm 電影感,淺景深,輕微手持呼吸感。

【動作節拍】
0-2 秒:自動門滑開,門鈴輕響,女生提著塑膠袋走到雨棚邊緣,抬頭看了一眼大雨。
2-4 秒:她轉向右側傘架,伸手要拿傘——手在半空停住:架上只有黑傘,紅傘不見了。
4-6 秒:她猛地抬頭四下張望,視線鎖定畫面左側——遠處那個路人正撐著她的紅傘走進雨幕,路燈把紅傘照成雨夜裡唯一一點紅。
6-8 秒:她站在雨棚邊緣沒有追,肩膀慢慢垮下來,抿了一下嘴,緩緩吐出一口氣;塑膠袋在她手邊輕輕晃。收尾定格:她停在原地,目光仍望向左側遠處的紅傘。

【物理】雨勢很大,雨絲在路燈逆光下清晰可見;雨棚邊緣連續滴水,地面積水映出霓虹倒影,路人踩過水窪濺起水花;塑膠袋隨手臂動作自然擺動。

【光線色彩】店內暖白光從背後勾出她的輪廓,街道整體是冷藍青色調,積水反射粉紫色霓虹;紅傘是全片唯一的高飽和紅色。

【聲音】無對白、無字幕、無配樂。聲音層次:密集雨聲、雨棚滴水聲、開場自動門滑開與門鈴聲、店內廣播音樂隨門關上而變悶消失、遠處車輪碾過濕路的聲音。

【結束狀態】女生獨自站在雨棚下,手提塑膠袋、手中無傘,望向左側;紅傘路人已幾乎沒入雨幕;鏡頭停在她的中近景。

【限制】人物恰好兩名,不多不少;紅傘只有一把且始終在路人手中;傘架裡自始至終只有深色傘;女生全程不撐傘、不追出去;畫面中不出現任何文字、字幕或浮水印。
```

## 使用說明與驗收要點

**選定平台後只需設定這幾個參數**(不用改 prompt 文字):時長 8 秒、長寬比(電影感建議橫幅寬螢幕)、解析度、是否開啟原生音訊(若平台不支援生成音訊,可忽略【聲音】段,不影響畫面)。

**出片後檢查**:① 只有兩個人、一把紅傘,且紅傘在路人手中而非女生手中;② 傘架裡沒有紅傘;③ 「伸手→停住→抬頭→看見→垮肩」的因果鏈完整可讀;④ 結尾停在她的中近景,沒有多餘剪接。

**最可能的失敗與單變數修法**(一次只改一項):
- 女生手上憑空出現雨傘 → 在【限制】加強:「她的雙手只有塑膠袋,從頭到尾沒有任何傘接觸她」。
- 紅傘路人太搶戲或走到前景 → 把路人改寫為「僅在最後 4-8 秒出現於左側遠景」。
- 8 秒塞不下、節奏太趕 → 刪掉 0-2 秒的「抬頭看雨」,讓她開門即走向傘架。
- 出現字幕或歌詞 → 保留「無字幕」禁令並移除【聲音】中「店內廣播音樂」一句(最常誘發 BGM 的來源)。

時間碼是節奏語意,不是逐幀保證;各平台對節拍的貼合度會有差異,屬正常現象。等你決定平台和版本後告訴我,我可以幫你轉成該平台的精確參數格式(例如 API 的 JSON 請求)。
