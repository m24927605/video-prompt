## 3. 驗收檢查(可逐項判是/否)

1. 畫面中恰好一人,無多餘人物或複製體。
2. 主角臉與髮型與 `@@Hero-A/台北#03` 一致;服裝**不**來自該參考。
3. 行走節奏(步頻、時序)與 `vid:route_B?cut=2` 一致;該參考的表演者外觀、場景、鏡頭**未**滲入。
4. 主角全程穿紅色雨衣;場景全程為雨夜巷口——即使任一參考素材呈現不同服裝或場景。
5. 行進方向為畫面左→右,無折返;踏水、雨滴滑落等物理反應可見。
6. 結尾為可剪接狀態:主角接近右側出鏡、動作連續、場景未變。

## 4. 失敗風險(無成功保證)

- **參考滲漏**:身分參考的服裝或背景覆蓋紅色雨衣/巷口——這是本案最高風險,因參考素材與使用者指定屬性直接衝突。
- **動作參考滲漏**:`vid:route_B?cut=2` 的表演者外觀或場景取代主角或巷口。
- **Token 解析未知**:兩個 token 的語法在未選定平台上可能不被識別;需在實際平台驗證其掛載方式(上傳槽位、欄位)後才可斷言行為。
- **方向漂移**:主角中途轉向或鏡頭運動抵銷左→右位移。

## 5. 修訂階梯(每次只動一個變數)

1. 若紅色雨衣被覆蓋 → 只強化服裝條款(在限制段加「參考一僅供臉與髮型,其服裝一律忽略」),其餘不動;仍失敗則路由到 `seedance-video-qc` 以輸出證據診斷。
2. 若行走節奏未被繼承 → 只改參考二的職責描述為更具體的節奏語言(步頻/落地時序),不動身分與場景。
3. 若場景被動作參考的環境取代 → 只在參考二的排除清單前置場景排除,不動其他段落。
