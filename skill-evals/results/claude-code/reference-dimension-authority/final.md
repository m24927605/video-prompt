## 1. 輸入基礎(Input basis)

- **任務**:reference-generate,單一 clip,單一 artifact。
- **平台/模型**:未選定。本 prompt 為平台中立;所有 runtime 參數(長寬比、時長、解析度、幀率、音訊通道)一律不寫入 prompt,列為未知。
- **參考 token**:`@@Hero-A/台北#03` 與 `vid:route_B?cut=2` 視為不透明字串,逐位元組原樣保留,未做任何改寫、正規化或重新編號。其在任一平台上的 runtime 解讀方式為**未知**——此語法是否被目標平台支援,需在使用者選定平台後另行查證。
- **職權對映(使用者明示,最高優先)**:token 1 → 僅主角臉與髮型;token 2 → 僅左至右行走節奏。紅色雨衣、雨夜巷口為使用者明示必守項,任何參考無權覆蓋。所有其他維度(光線、色彩、鏡頭、風格、音訊、身形、姿勢……)**無得主、不啟用**,不從上傳順序或媒體類型推斷歸屬。
- **標註為假設的補足內容**(使用者未指定,為使 clip 可拍而補,均可退回):開場時行走已在進行中;兜帽不遮臉(否則臉/髮參考無法驗收);固定機位中景偏廣;雨聲+腳步聲的封閉音訊集、無音樂無對白;巷口既有光源(街燈類)作為受動機光源。
- **未知**:目標平台與模型、容器幾何、時長、該平台是否輸出音訊、兩個 token 是否為該平台可解析的語法。

## 2. 最終 Prompt(平台中立,可直接使用)

```text
【任務與意圖】
生成一段連續單一鏡頭的影片 clip:雨夜的巷口,一名主角穿紅色雨衣,
由畫面左側走向畫面右側。全片一個主要事件:這一次不間斷的橫向步行。

【總則(本 prompt 內衝突時,此段為準)】
紅色雨衣與雨夜巷口為硬性要求,由本文指定;任何參考素材中出現的
服裝、地點、天氣、光線均不得取代它們。
兩個參考各自只擁有下列一項職權,職權清單即為完整清單,再無其他。

【啟用參考與職權】
來源:使用者提供的參考 token 「@@Hero-A/台北#03」(原樣保留,不得改寫)
目標:片中唯一主角
作用時段:整段 clip
允許繼承:臉部特徵、髮型——此兩項為該參考職權的完整清單
排除繼承:身形比例、體態、服裝、配件、姿勢、動作、構圖、背景、
光線、色調、風格、聲音;來源中若出現任何衣著或場景,一概不進入本片

來源:使用者提供的參考 token 「vid:route_B?cut=2」(原樣保留,不得改寫)
目標:主角由畫面左至畫面右的步行
作用時段:整段行走期間
允許繼承:左至右步行的節奏——步頻、步幅節拍、落腳韻律;此一項為完整清單
排除繼承:表演者身分、臉、髮型、服裝、道具、地點、背景、鏡頭運動、
構圖、光線、色彩、風格、音訊

除上述兩項職權外,不存在其他啟用參考;未列出的維度不由任何參考控制。

【實體(硬性)】
畫面中恰好一個人,無第二個人影、無鏡像或倒影複製人。
主角穿一件紅色雨衣,雨衣表面被雨打濕、有光澤反光;兜帽不遮擋臉與髮型,
臉部與髮型全程清楚可見並依「@@Hero-A/台北#03」呈現。
若臉與髮型不符該參考,或雨衣不是紅色,本 take 作廢。

【空間與走位】
夜晚的巷口:巷子開口位於畫面中景,地面濕滑積水、反射光源。
主角自畫面左緣外走入,沿約與畫面平行的路線橫越巷口前,走向畫面右側。
行進方向全程為畫面左至畫面右,不回頭、不折返、不左右鏡像翻轉。
(以上左右均指畫面矩形的左右。)

【開場條件】
第一格時主角已在行走中,步行節奏已依「vid:route_B?cut=2」進行,
不從靜止起步。

【鏡頭】
固定機位,與主角視線同高的中景偏廣,焦點保持在主角。
唯一允許的鏡頭狀態是完全靜止:無搖攝、無俯仰、無滾轉、無推拉、
無橫移、無環繞、無升降;不採用俯瞰或空拍視角。

【單鏡完整性】
連續單一鏡頭,無內部剪接、無疊化轉場、播放速率恆定不變。

【動作與物理】
主要事件:一次完整的左至右步行,節奏(步頻與落腳節拍)依
「vid:route_B?cut=2」,僅取其節奏,不取其人物與場景。
每一步落在積水地面產生小水花與漣漪;雨持續下落,
雨滴在光源前可見,打在雨衣上形成連續的細碎反光。
步行速度與節拍全程保持一致,此為必須維持的不變項:
自第一格至最後一格,若節奏明顯加速、減速或停頓,即為違反。

【表演與嘴型】
全片無對白。主角雙唇閉合放鬆,除自然呼吸外不形成任何音節性嘴型。
視線朝行進方向前方,不看鏡頭。

【光線與材質】
光源為巷口既有的夜間街燈類光源,方向來自主角行進路線的前上方;
濕地面與雨衣以鏡面反光回應光源。全程無突兀的光線變化。

【畫面內文字】
巷口牆面與任何表面上不得出現可辨識文字,也不得出現自創字形、
類文字符號、殘缺或拼錯的字樣;牆面與招牌位置以雨水反光、
材質紋理與老舊痕跡呈現,任何位置皆無可讀的字母、數字或漢字。

【音訊(封閉清單)】
本 clip 只允許以下聲音:持續的雨聲環境音(來自畫面中的降雨)、
主角踩過積水的腳步聲(與畫面落腳同步)。
除此之外無其他聲音:無音樂、無人聲、無旁白、無字幕。

【結束狀態】
最後一格:主角仍在行走中,已行至畫面右側三分之一處,
面向與動勢仍為畫面右方;紅色雨衣、臉部、髮型與步行節奏
自始至終未變;雨未停,鏡頭未動。
```

## 3. 驗收檢查(逐項可判是/否)

- 畫面中恰好一人;無複製人、無倒影分身。
- 臉與髮型與 `@@Hero-A/台北#03` 一致;該參考來源的服裝、背景、光線**沒有**出現在片中。
- 雨衣為紅色且濕潤;地點為雨夜巷口——即使任一參考來源顯示不同服裝或場景。
- 步行節奏與 `vid:route_B?cut=2` 的節拍一致,且全程恆定;該來源的人物、場景、鏡頭**沒有**滲入。
- 行進方向自始至終為畫面左至右,無鏡像翻轉、無折返。
- 鏡頭完全靜止;單一連續鏡頭,無內部剪接、無速率變化。
- 嘴唇閉合,無音節嘴型;無可讀文字或類文字符號;音訊只有雨聲與腳步聲。
- 結尾:主角在畫面右側三分之一、仍在行走。

## 4. 失敗風險(與本任務相關者)

- **臉部參考的服裝滲漏**:身分參考最常夾帶來源衣著。已用排除清單+「紅色雨衣為硬性、可作廢」防守,但無成功保證。
- **節奏參考的身分/場景滲漏**:影片類參考容易連人帶景繼承;已逐項排除,仍為最高風險軸。
- **方向鏡像翻轉**:橫向行走 clip 的已知失效模式;已單獨設「不鏡像翻轉」防護。
- **牆面出現類文字碎形**:雨夜巷口是常帶招牌的表面,已用「malformation 防護+正向材質描述」雙句處理。
- **token 不被目標平台解析**:兩個 token 的語法是否有效完全取決於尚未選定的平台;若平台無此機制,需改以該平台的上傳/引用方式綁定,token 文字本身仍不改寫。

## 5. 修訂階梯(每級只動一個變數)

1. **節奏滲漏場景/人物** → 只在 token 2 的排除清單前加一句總則級聲明「該來源僅為節奏參考,其畫面內容一概不得出現」,其餘不動。若兩次仍滲漏 → 改用純節奏描述(步頻/節拍文字化)取代該參考,轉入診斷。
2. **臉部參考夾帶衣著** → 只將雨衣句改為逐件封閉衣著清單(雨衣+其下衣物明寫),其餘不動。仍失敗 → 拆為先產首幀定裝、再以首幀生成的兩個依序 artifact。
3. **方向翻轉** → 只增加一個畫面右側的具名地標並讓路線指向它,其餘不動。仍翻轉 → route 到 `seedance-video-qc` 以實際輸出證據診斷。
4. **節奏不恆定** → 只把節奏不變項改寫為分段節拍描述(每步等間隔),其餘不動;兩次無效即停止,回報平台限制。
