## 3. Acceptance checks（逐項可判定）

- 全片有且只有兩人；鏡面／玻璃反射無多出人形。
- 阿晴始終在畫面左、阿朗在畫面右門內；無人越過中線或接觸。
- 台詞歸屬正確：第一句出自阿晴、第二句出自阿朗，**不可對調**；粵語發音自然、與口型對得上。
- 阿朗開口前有可見的一拍停頓（吸氣／重心轉換在先）。
- 音軌只有：雨聲、與動作同步的抹布摩擦聲、開場門鈴餘響、兩句對白。無 BGM、無字幕、無畫面文字。
- 結束幀：阿晴手停但頭未轉；阿朗仍在門內原位；鏡頭全程未動、未剪接。

## 4. Failure risks（僅列與本鏡頭相關）

- **粵語對白與口型**：AI 影片模型對粵語口語的發音準確度與 lip-sync 是已知弱項；最壞情況預留後期配音（ADR）方案。
- **台詞對調或多講**：雙人對白鏡頭常見講者錯配；prompt 已用「不得對調／唔再出聲」鎖定，但仍是最高風險項。
- **鏡面反射生出第三人**：茶餐廳大鏡屬場景特徵，已明文禁止多餘人形。
- **「不回頭」被演成回頭**：模型傾向讓聽者轉頭望講者；已用「視線停留喺枱面」正向鎖定。
- 無任何平台能保證一次成功；以上是風險而非缺陷預告。

## 5. Revision ladder（每次只改一個變量）

1. **台詞錯配** → 只改：在對白區塊為兩人各加一句「（阿朗此時只聽，唔出聲）」式的沉默標記。其餘不動。仍錯 → 拆成兩個鏡頭（正反打）再後期剪。

3. **粵語發音差** → 只改：平台若支援音訊參考，加一段粵語聲線參考；否則保留畫面、路由到後期配音。
