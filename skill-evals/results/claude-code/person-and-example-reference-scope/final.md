## 4. Failure risks(任務相關風險,無成功保證)

- **雙人參考互相污染**:兩張人物參考同場時,常見臉部特徵混合或服裝互滲(男主染上綠外套元素、女主服裝變異)。
- **服裝覆寫失敗**:@Image 2 的圖中服裝可能滲入,或「紅色救援制服」被模型自由發揮出臃腫的裝備細節。
- **手部與持有權**:交接是手部特寫級的物理事件,最易出現信瞬移、雙手同時持信到結尾、信落入左手、或多出一封信。
- **時長與節拍**:12 秒是否為你的平台支援的 duration 值未知;時間節拍是語意節奏,不保證逐秒對齊。
- **雨水材質**:信封可能被錯誤渲染成濕的;地面反射可能產生「倒影分身」。

1. **持有權失敗(信不在右手/雙手持信)**:只強化 6–9 秒節拍,將「她鬆手」與「他右手獨握」拆成兩個相鄰子節拍,並在結束狀態重複一次「左手空且可見」。其他區塊不動。
