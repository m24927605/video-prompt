## 2. Final prompt

```text
[任務與意圖]
以參考圖生成一段連續 12 秒的單一鏡頭:雨夜露天火車月台上,女主將唯一一封信交給男主;結尾時信只在男主右手。這是本片唯一的主要事件。

[精確實體]
畫面中自始至終恰好兩個人:角色A(女主)、角色B(男主),無第三個人形、無路人、無倒影複製人形。恰好一封已封口的信封,全片只存在這一封。硬性要求:任一畫格出現第三個人形或第二封信,該次生成作廢。

[參考素材與職責]
@Image 1 = 角色A(女主)的完整人物參考。
採用:臉、髮型、身形比例、深綠色長外套、黑色靴子、銀色墜飾;以上即此參考管轄的全部通道,清單已封閉。
不繼承:來源圖的背景、姿勢、構圖、裁切、光線,以及圖中任何其他人物。
@Image 2 = 角色B(男主)的臉與身份參考,僅此一項職責,清單已封閉。
不繼承:來源圖的服裝、配件、背景、姿勢、構圖、裁切、光線。
硬性要求(管轄整段影片):角色B的服裝只由本文規定——紅色救援制服;任何參考影像中的服裝都不得出現在角色B身上。

[場景與空間]
夜間露天火車月台,穩定降雨。空間兩側固定命名:「軌道側」與「站房側」;頂棚沿站房側延伸,棚簷之外雨絲可見。兩人站在棚簷下、月台中段;以本鏡頭畫面而言,角色A在畫面左、角色B在畫面右,相距一步,約四分之三側面相對,視線落在對方臉上。背景(軌道側)是濕亮的月台邊緣與雨夜散景燈光。此配置即本片唯一的地理,不得增加本段未寫的建物或軌道結構。

[第一幀與開場狀態]
第一幀時兩人已就位如上;角色A右手在腰際持該信封,信封朝向角色B;角色B雙手垂放身側。動作已在進行:角色A正開始抬起右手。

[鏡頭]
中景雙人鏡頭起,鏡頭高度與兩人視線齊平;不允許俯視、鳥瞰或任何高於視線的機位。唯一的鏡頭運動是緩慢向前推近,推向兩人之間交接的手,並在最後一秒緩慢減速停定;無平搖、無俯仰、無滾轉、無橫移、無升降、無環繞、無變焦。機身為穩定承托的移動,無手持晃動。焦點始終在兩人與信封上;背景燈光化為柔和散景(可詮釋描述)。

[時間節拍](秒數為節奏語意,非逐幀精確)
0–4 秒:角色A抬起右手,將信封遞向角色B;她的視線先落在信封,再抬到角色B臉上。
4–8 秒:角色B抬起右手,手指從信封另一端合攏握住;約一秒鐘兩人各持信封一端,信封在兩人之間水平停頓。
8–12 秒:角色A鬆手,右手收回身側;角色B右手單獨持信,微微收向胸前;兩人視線在對方臉上停住。

[物理]
信封是輕的紙製品:遞出與交接只有手臂與手指的力,信封不飄動、不彎折變形;零星雨點在信封表面留下小塊深色濕斑。雨自上方垂直落下,棚簷邊緣有連續滴水;月台地面濕亮並反射燈光。

[表演(可觀察行為)]
兩人全程不說話。畫面層面的硬性要求:兩人嘴唇全程閉合放鬆、不做任何口型;唯一例外是角色A鬆手時可見一次緩慢吐氣,夜間冷空氣中呈一縷白霧,吐氣不形成音節口型。角色A:遞信時指尖在信封邊緣多停半拍,鬆手前拇指輕壓一次信封角。角色B:接信時先看角色A的眼睛,再低頭看信封一眼,再抬眼。

[信封與畫面內文字]
信封為米白色素面紙、已封口,表面只有紙的纖維紋理與雨濕斑點;信封上沒有任何可讀的文字或數字,不得出現臆造字形、類文字符號、殘缺或拼錯的字樣。背景若出現站牌或告示,同一規則:形體存在但不解析為可讀字元,不得出現臆造字形。畫面上不疊加任何字幕、標題或浮水印。

[光線與色彩]
主光來自站房側頂棚下的月台燈,偏暖鎢絲色,從上方略側打在兩人臉上;軌道側背景為偏冷藍青的雨夜。深綠外套與紅色制服保持可辨的色彩對比。光線狀態全程不變。

[聲音](封閉清單,除下列外不得有任何聲音)
持續雨聲(來源:棚外落雨)、棚簷滴水聲(來源:畫面內棚簷)、低微的車站環境底噪(來源:場景本身)。無對白、無旁白、無音樂、無字幕、無任何人聲;兩人全程靜默。

[全程不變項(第一幀至最後一幀)]
恰好兩人、恰好一封信;角色A的深綠長外套、黑靴與銀色墜飾持續可見且不改變;角色B全程穿紅色救援制服不改變;雨、夜色與光線狀態不變;單一連續鏡頭,無內部剪接、無轉場、無播放速率變化。

[結束狀態]
最後一幀:信封只在角色B的右手中、貼近其胸前;角色A雙手皆空、垂放身側;兩人視線相對;鏡頭推近已停定,構圖為偏近的雙人中近景。硬性要求:最後一幀若信封仍在角色A手中、或在角色B左手、或兩人同時持信,該次生成作廢。
```

## 3. Acceptance checks(逐項可觀察驗收)

- 全片恰好兩人、恰好一封信;無第三人形、無第二封信、無倒影複製。
- 女主 = @Image 1 的臉/髮/身形,且深綠長外套、黑靴、銀墜飾三件全程在畫且未變;背景、姿勢、光線與來源圖無關。
- 男主 = @Image 2 的臉,服裝為紅色救援制服;@Image 2 的原服裝任何元素(顏色、款式、配件)未出現。
- 交接順序可見:她右手遞 → 兩端同持約一秒 → 她鬆手 → 最後一幀信只在他右手。
- 鏡頭只有一個緩慢前推並停定,視線高度,無其他軸向運動、無剪接、無速率變化。
- 兩人全程閉唇,唯一例外是女主一次可見吐氣;信封與背景無可讀字元、無臆造字形;無字幕。
- 音軌只含雨、滴水、環境底噪;無音樂、無人聲。

## 4. Failure risks(僅列本任務相關,無成功保證)

- **服裝滲入**:face-only 參考仍可能帶入 @Image 2 的原服裝,尤其在中景;prompt 已把「服裝只由本文規定」提升為管轄全片的硬性條款,但這是文字意圖,非保證。
- **交接失敗**:換手是最常見的物理失敗點——信封複製、瞬移、換到左手。已用「兩端同持一秒」的中間態降低風險。
- **字形殘渣**:信封與站牌是天然帶字表面,可能出現似字非字的符號;已同時給了禁令與正面表面描述(纖維紋理+濕斑)。
- **無聲口型**:靜默角色仍可能被畫成張口說話;已在畫面側鎖定閉唇並開了吐氣例外。

## 5. Revision ladder(每階只改一個變數,其餘全部保持)

1. **信封複製或換錯手** → 把 4–8 秒交接改為「手部特寫插入鏡」單獨生成(其餘節拍不動)。若插入鏡仍失敗兩次,改走首末幀(first/last-frame)任務鎖定結尾持信狀態——那是另一份 artifact,需另行撰寫。
2. **男主服裝滲入** → 只補一項:為紅色救援制服增加部件級正面描述(領型、前襟、反光條位置),不動其他區塊。仍滲入則改用一張紅制服的服裝參考圖(需你提供),重寫參考映射。
3. **信封出現字形** → 只改信封段:縮小信封在畫面中的尺寸敘述(交接時信封背面朝鏡頭)。仍失敗則接受後製合成素面信封,停止用 prompt 解決。
4. **鏡頭多餘運動** → 只改鏡頭段:放棄推近,改全程鎖定機位。此項與 1–3 不同時改。
