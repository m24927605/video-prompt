## 1. Input basis(輸入依據)

- **任務類型**:edit(單一主操作;唯一 master 為 @Video 1)。
- **平台/模型**:未指定 → 本 prompt 為平台中立。所有 runtime 參數(長寬比、解析度、時長欄位、任務提示欄位、遮罩上傳方式等)一律**不填寫、不發明**,待選定平台後依其現行官方文件補上。
- **標記假設**:紅色方框與藍色箭頭僅是「向人類說明意圖區域」的註記;**不假設任何平台能讀取畫面上的標記**,因此 prompt 內同時以語言完整描述目標物。若所選平台支援標註式編輯(marked edit),此 prompt 可直接沿用;若不支援,語言描述本身已足以定位目標。
- **未知項**:原片是否在 4 秒前或 7 秒後也出現該馬克杯(未提供影片內容細節);以使用者規格為準——僅 4–7 秒替換。

## 2. Final prompt(可直接貼用)

```text
[任務]
編輯 @Video 1。@Video 1 是唯一 master 影片。只執行一項修改:在第 4 秒至第 7 秒之間,
把桌面上那一個藍色馬克杯替換為一個白色陶瓷花瓶。除此之外不做任何其他修改。

[目標物定位]
目標物是畫面中唯一的藍色馬克杯,位於桌面上(即參考標註中紅色方框框選、藍色箭頭
指向的那一個物件)。紅框與箭頭僅用於說明編輯區域,不是畫面內容;最終輸出畫面中
不得出現紅色方框、藍色箭頭或任何標註圖形。

[替換規格 A→B]
白色陶瓷花瓶精確佔據藍色馬克杯原本的位置:相同的桌面接觸點、相同的畫面尺度、
相同的透視角度與朝向。花瓶為素面白色陶瓷,表面帶釉面光澤;瓶內不加花、不加水,
不新增任何其他物件,花瓶在整段期間不移動。

[繼承項]
花瓶完整承接原馬克杯在畫面中的一切空間關係:被手部或其他物件遮擋時,遮擋邊界
與時間點不變;桌面上的接觸陰影位置、形狀、柔硬度不變;場景中對該物件的反射
(如桌面或鄰近光滑表面)改為反射白色陶瓷花瓶,反射位置與強度邏輯不變;
光照方向與強度不變,僅材質反應改為白色釉面陶瓷的可見高光。

[保留清單 — 全片逐項不變]
人物的身分、數量、姿態與表演;手部動作的軌跡與時間節奏;桌上其他所有物品的
位置與狀態;背景;透視;所有遮擋關係;接觸陰影;反射;機位與運鏡;光線;調色。
全部聲音原樣保留:對白、環境音、動作音效、背景音樂一律與 @Video 1 完全一致,
不重配、不靜音、不改變音量。

[時間範圍]
替換僅發生在第 4 秒至第 7 秒之間。第 4 秒之前與第 7 秒之後,畫面與聲音
與 @Video 1 逐幀一致,不得有任何改動。

[結束狀態]
第 7 秒之後,影片與原始 @Video 1 完全相同;整段輸出的時長與 @Video 1 相同。
```

## 3. Acceptance checks(可觀察驗收)

- 0–4 秒與 7 秒–片尾:逐幀與原片一致(抽查首幀、3.9s、7.1s、末幀)。
- 4–7 秒:藍色馬克杯不出現;白色陶瓷花瓶出現在同一桌面接觸點、同尺度、同透視。
- 手部經過該物件時,遮擋邊界與時間點與原片相同;接觸陰影與反射跟隨花瓶而非殘留馬克杯形狀。
- 桌上其他物品、人物、背景、機位、光線、調色無任何漂移。
- 音軌與原片完全相同(波形/聽感比對),無重配或斷點。
- 輸出畫面中無紅框、箭頭或任何標註圖形。
- 4s 與 7s 邊界幀:物件切換即為規格所定,確認切換發生在指定時刻附近且無其他區域連帶變化。

## 4. Failure risks(不保證成功)

- **邊界可見切換**:依規格物件只在 4–7 秒替換,4s/7s 處會有馬克杯↔花瓶的可見跳變;若原片在該區間外也拍到馬克杯,這是規格內結果,不是缺陷。若實際上希望全片替換,需改規格。
- **保留措辭非硬保證**:編輯模型常見未觸及區域漂移(人物臉部、調色、音軌被重生成);需靠驗收抽查,而非假設 preserve 必然生效。
- **時間精度**:4–7 秒是語意區間,多數模型不承諾逐幀精確的時間定位。
- **反射/陰影一致性**:複雜反射面上的物件替換是常見弱項,可能殘留藍色色偏。

## 5. Revision ladder(每次只改一個變數)

1. 若標記圖形滲入輸出 → 僅強化「輸出中不得出現任何標註圖形」一條,其餘不動。
2. 若花瓶尺度或位置漂移 → 僅在替換規格中加入相對地標描述(如「瓶口高度與原杯口一致、底部貼合原杯底接觸點」)。
3. 若音軌被改動 → 僅把聲音保留條款提到 prompt 最前段;若仍失敗,改走後製:取原片音軌回貼(路由至剪輯,停止改 prompt)。
4. 若 4 秒前/7 秒後出現漂移 → 停止用單次全片編輯,改為只送 4–7 秒片段編輯後與原片段落剪接合成(路由至剪輯流程)。
5. 任一缺陷在兩次單變數修正後仍存在 → 停止重試,轉入 QC 診斷(seedance-video-qc)。
