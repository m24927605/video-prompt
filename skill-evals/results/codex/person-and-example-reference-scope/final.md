## Input basis

- 任務：12 秒、單一連續鏡頭的多參考生成。
- 平台／模型：未指定；以下為平台中立 prompt。
- 輸入模式：以 `@Image 1`、`@Image 2`、`@Video 1` 作語意參考；實際綁定方式需依所用平台設定。
- 時碼代表語意節奏，不保證逐幀精準。
- 假設：無對白、無字幕、無配樂；保留雨聲、車站環境聲與衣料／信封接觸聲。
- 未知參數：畫面比例、解析度、幀率、種子及平台專用欄位。

## Final prompt

```text
[TASK AND INTENT]

生成一段 12 秒的單一連續 clip，不切鏡。雨夜車站月台上，女主把全場唯一一封完整封口的紙信親手交給男主；所有動作清楚呈現信件所有權由女主轉移至男主。結尾時，信只能位於男主右手，女主雙手完全空著。

[ACTIVE REFERENCES AND ROLES]

@Image 1
Target：女主，整段 clip。
只繼承：女主可見的臉與身份、髮型、身形比例、深綠色長外套、黑色靴子、銀色墜飾。
不要繼承：原圖背景、姿勢、動作、構圖、鏡位、裁切、景深、光線、色調或其他人物。女主必須依本 prompt 重新站位和表演。

@Image 2
Target：男主，整段 clip。
只繼承：男主的臉部特徵與身份辨識；保持同一人物。
不要繼承：原圖服裝、制服、配件、身體姿勢、背景、構圖、裁切、光線或色調。髮型不得遮住臉。男主在本片明確穿著紅色救援制服。

@Video 1
Target：僅作為 prompt 組織方式的結構參考。
只繼承：提示詞的段落層級、控制深度與細節密度。
絕對不要繼承：故事、事件、第一人稱 POV、任何鏡頭設計或運鏡、視覺風格、人物、服裝、場景、道具、素材、動作、對白、聲音或結局。

[EXACT ENTITIES]

畫面中始終只有兩個真人：一名女主和一名男主。不得出現第三人、群眾、倒影形成的人物複製或身份融合。

全場始終只有一封信：一個薄的、完整封口的淺色紙信封。沒有第二封信、散落信紙、信件複製品或其他紙張。

女主穿深綠色長外套和黑色靴子，胸前銀色墜飾保持可見。男主穿完整、清楚可辨的紅色救援制服；不得穿 @Image 2 中的服裝。

[LOCATION AND SPATIAL MAP]

雨夜的室外車站月台。月台雨棚、濕亮地面、軌道與遠處模糊的站燈建立環境；雨落在雨棚外側，風把少量雨霧吹入月台邊緣。

女主站在畫面左側，男主站在畫面右側，兩人相隔約一步，彼此呈三分之四側身並面向對方。兩張臉都朝向鏡頭一側，持續可辨。保持固定越軸關係，不交換左右位置。

[FIRST FRAME AND BLOCKING]

第一幀已完整建立兩人與唯一信封。女主右手在腰前握住信封短邊，信封完整可見；左手自然垂下。男主雙手空著，右手位於紅色制服袖口下方且清楚可辨。

以全身雙人景開始，女主的臉、髮型、身形、深綠長外套、黑靴及銀色墜飾全部可見；男主的臉與紅色救援制服清楚可見。

[OPTICS AND CAMERA]

客觀第三人稱視角，禁止第一人稱 POV。攝影機位於兩人正面略偏月台內側、胸口高度，以自然透視的全身雙人構圖拍攝。

整段只有一個極慢、平穩的向前推近，從全身雙人景收至約膝上雙人景；不得繞行、甩鏡、手持晃動、突然變焦或切鏡。交信接觸時焦點落在兩人的手和唯一信封，隨後平順回到兩張臉。不得因推近而在交信前裁掉女主黑靴。

[TIMECODED ACTION BEATS — SEMANTIC PACING]

0.0–3.0 秒：
兩人靜立相望。女主右手握著唯一信封，先看男主的眼睛，再短暫低頭看信。她吸一口短促的氣，拇指在信封邊緣停住。男主雙手仍空著，沒有提前碰信。

3.0–6.5 秒：
女主將右手連同信封緩慢伸向兩人之間。信封沿近乎水平的短路徑移動，始終只有一個。男主先看信封，再把清楚可辨的右手伸出，右掌向上；左手保持放鬆並遠離信封。

6.5–8.5 秒：
女主把信封短邊放入男主右手掌心。男主右手手指接觸信封後才閉合並穩定握住。接觸期間可以短暫由兩人同時觸碰同一封信，但不得生成第二封信，也不得把信交到男主左手。

8.5–10.0 秒：
男主右手已承受信封全部重量。女主依序鬆開右手手指並把右手撤回；所有權轉移完成。男主左手仍不接觸信封。

10.0–12.0 秒：
男主把唯一信封穩定留在右手、置於腰側可見位置，抬眼看向女主。女主雙手分開並保持完全空著，垂在身體兩側；她看他一秒，輕微吞嚥後移開視線。兩人停住，形成可直接剪接的結尾定格狀態。

[PHYSICS AND PROP CONTINUITY]

信封是有輕微挺度的紙質物件，移動時只產生細小彎曲，不像布料飄動。雨和風不會把信封吹走。

交接因果必須依序為：女主握住信封 → 女主伸手 → 男主右掌接觸 → 男主右指閉合承重 → 女主手指鬆開 → 女主撤手。信封不可瞬移、穿過手掌、消失、變形、翻倍或在兩手間跳動。

[OBSERVABLE ACTING]

女主的目標是完成告別但不延長接觸：肩膀略緊，呼吸克制，遞信前拇指停頓一次；交出後立刻收回空手，不擁抱、不握手、不哭喊。

男主的目標是接下信並保持鎮定：等待信封靠近後才伸出右手，接住時下顎短暫收緊；確認握穩後才重新看向女主。不做敬禮、奔跑或其他救援動作。

表演安靜、細微、寫實，不說話，不做誇張表情。

[LIGHT, COLOR, MATERIAL]

寫實雨夜。冷色車站頂燈從上方照亮兩張臉與濕外套輪廓，遠處暖色站燈形成少量背景層次。濕月台產生受控反光，但反射中不得形成額外人物。

深綠外套、紅色救援制服和銀色墜飾保持彼此可辨；紅色制服不能被夜色染成黑色或其他顏色。皮膚色調自然，臉部不被陰影、雨水或頭髮遮住。

[AUDIO]

無對白、無旁白、無字幕、無畫面文字、無背景音樂。只有連續雨聲、遠處低弱的車站環境聲、輕微風聲、衣料移動聲，以及交信時一次細小的紙張摩擦聲。不得加入火車鳴笛或廣播來搶占交信節點。

[END STATE — HARD REQUIREMENT]

最後可見狀態中：
只有男主右手持有唯一信封；男主左手空著並與信分離。
女主雙手完全空著、彼此分開，且與信封保持清楚距離。
畫面內仍只有兩人和一封信。
兩人沒有身體接觸。
女主仍穿深綠長外套、黑靴與銀色墜飾；男主仍穿紅色救援制服。
攝影機停止推近並穩定停留，信封和兩張臉均可辨。
```

## Acceptance checks

- 始終只有兩人、一封信；沒有複製、融合或第三人。
- 女主完整保留指定身份、髮型、身形與服裝配件；男主只繼承指定臉部身份並穿紅色救援制服。
- 使用客觀第三人稱單鏡頭，沒有繼承 `@Video 1` 的內容或視聽設計。
- 信件按照接觸、承重、鬆手、撤手的順序完成一次轉移。
- 最後只有男主右手持信；其左手與女主雙手皆清楚空著。
- 無對白、字幕或配樂；雨聲及接觸聲符合畫面因果。

## Failure risks

- 左右手辨識錯誤，導致男主左手接信。
- 接觸瞬間生成第二封信，或女主撤手後仍黏著信封。
- 全身構圖、臉部可見性、墜飾與交信手部特寫互相競爭。
- 參考素材越界，使男主沿用 `@Image 2` 服裝，或使 `@Video 1` 的內容滲入成片。

## Revision ladder

1. 若只發生左右手錯誤：將攝影機改為完全固定的正面全身雙人景；其餘內容不變。重試一次。
2. 若只發生信件複製：把 6.5–10 秒簡化為男主右掌已固定在中央、女主只執行「放入—鬆開—撤回」；其餘不變。重試一次。
3. 若參考仍越界：移除 `@Video 1` 後以完全相同的文字 prompt 生成；不改人物、動作或結局。
4. 若兩次聚焦重試後仍無法可靠呈現單封信與右手所有權，停止加長 prompt，改用交信末態關鍵幀／構圖參考，或拆成獨立交信 insert。
